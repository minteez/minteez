# 🧮 MathLab

One of my biggest projects so far.

**MathLab** began as a school Science Exhibition project and grew into an interactive mathematics platform.

The project explores mathematics through:

* 📚 Concept learning
* 🧪 Interactive mathematical experiments
* 📐 Formula exploration
* 🧊 3D geometry
* 🧠 Mathematical thinkers
* 🎮 Interactive challenges
* 🌍 Mathematics in the real world
* 🧩 Puzzles and problem solving

The bigger idea behind MathLab is simple:

> **Make mathematics something you can explore, not just something you can read.**
